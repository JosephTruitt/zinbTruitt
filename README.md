# zinbTruitt

Negative binomial (`nbreg()`) and zero-inflated negative binomial (`zinbreg()`)
regression fitted with IRLS, Newton-Raphson, and EM. STA 651 final project.

## Installation

# install.packages("devtools")
devtools::install_github("JosephTruitt/zinbTruitt")
