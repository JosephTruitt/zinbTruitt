Negative Binomial and Zero-Inflated Negative Binomial Regression in R: IRLS, Newton–Raphson, and EM Without a General-Purpose Optimizer

Joseph Truitt

November 2026

1 Introduction

Count outcomes such as the number of articles an author publishes or the number of physician visits a patient makes are routinely analyzed with Poisson regression. The Poisson model forces the variance to equal the mean, an assumption that real count data usually violate in two ways. First, the data are often overdispersed: the variance exceeds the mean because of unobserved heterogeneity. The negative binomial (NB) model handles this by adding a dispersion parameter θ\theta. Second, the data often contain more zeros than even an NB model predicts, because some units are never at risk of a positive count. The zero-inflated negative binomial (ZINB) model handles this by mixing the NB distribution with a point mass at zero (Lambert, 1992; Cameron and Trivedi, 2013).

The standard R implementations, MASS::glm.nb() and pscl::zeroinfl(), are reliable but treat the estimation as a black box. The goal of this project was to build an R package, zinbTruitt, that fits both models from first principles and reproduces the reference implementations. The estimation uses only closed-form building blocks: iteratively reweighted least squares (IRLS) for regression coefficients, Newton–Raphson for the dispersion parameter, and the EM algorithm (Dempster, Laird and Rubin, 1977) for the zero-inflation mixture. No call to optim() or any other general-purpose optimizer is made.

The report describes the algorithms (Section 2), the package (Section 3), agreement with the reference functions on two data sets (Section 4), a simulation study (Section 5), an analysis of physician office visits in the 1987–88 National Medical Expenditure Survey (Section 6), and limitations (Section 7). All numbers, tables, and figures are produced by code in this document that calls the installed package.

2 Methods

2.1 Negative binomial regression

Let YiY_i be a count with covariate vector xix_i and optional offset oio_i. The NB2 model has probability function P(Yi=y)=Γ(y+θ)Γ(θ)y!(θθ+μi)θ(μiθ+μi)y,log⁡μi=xi⊤β+oi, P(Y_i = y) = \frac{\Gamma(y + \theta)}{\Gamma(\theta)\,y!}\left(\frac{\theta}{\theta + \mu_i}\right)^{\theta}\left(\frac{\mu_i}{\theta + \mu_i}\right)^{y}, \qquad \log \mu_i = x_i^\top\beta + o_i, so that E(Yi)=μiE(Y_i) = \mu_i and Var(Yi)=μi+μi2/θ\mathrm{Var}(Y_i) = \mu_i + \mu_i^2/\theta with θ>0\theta > 0. As θ→∞\theta \to \infty the model reduces to Poisson. With prior weights aia_i (all equal to one for an ordinary fit) the log-likelihood is ℓ(β,θ)=∑iai[log⁡Γ(yi+θ)−log⁡Γ(θ)−log⁡yi!+θlog⁡θ+yilog⁡μi−(θ+yi)log⁡(θ+μi)]. \ell(\beta, \theta) = \sum_i a_i\Big[\log\Gamma(y_i + \theta) - \log\Gamma(\theta) - \log y_i! + \theta\log\theta + y_i\log\mu_i - (\theta + y_i)\log(\theta + \mu_i)\Big]. This is the parameterization of MASS::glm.nb().

IRLS for β\beta (with θ\theta fixed). The log link gives ∂μi/∂ηi=μi\partial\mu_i/\partial\eta_i = \mu_i and the variance function is V(μi)=μi+μi2/θV(\mu_i) = \mu_i + \mu_i^2/\theta. Fisher scoring is then equivalent to repeated weighted least squares with working weights and working response wi=ai(∂μi/∂ηi)2V(μi)=aiθμiθ+μi,ui=(ηi−oi)+yi−μiμi, w_i = a_i\,\frac{(\partial\mu_i/\partial\eta_i)^2}{V(\mu_i)} = a_i\,\frac{\theta\mu_i}{\theta + \mu_i}, \qquad u_i = (\eta_i - o_i) + \frac{y_i - \mu_i}{\mu_i}, β(t+1)=(X⊤WX)−1X⊤Wu,W=diag(w1,…,wn). \beta^{(t+1)} = (X^\top W X)^{-1}X^\top W u, \qquad W = \mathrm{diag}(w_1, \dots, w_n). The working response uiu_i is a first-order Taylor expansion of the link function at the observed yiy_i, and its approximate variance is 1/wi=1/μi+1/θ1/w_i = 1/\mu_i + 1/\theta, the sum of a Poisson component and an overdispersion component. The weighted least squares step is solved by a QR decomposition. Because uiu_i and wiw_i depend on μi\mu_i, and hence on β\beta, the step is repeated until the log-likelihood stops changing.

Newton–Raphson for θ\theta (with β\beta fixed). The score and second derivative of ℓ\ell in θ\theta are U(θ)=∑iai[ψ(yi+θ)−ψ(θ)+log⁡θ+1−log⁡(θ+μi)−yi+θθ+μi], U(\theta) = \sum_i a_i\Big[\psi(y_i + \theta) - \psi(\theta) + \log\theta + 1 - \log(\theta + \mu_i) - \tfrac{y_i + \theta}{\theta + \mu_i}\Big], H(θ)=∑iai[ψ′(yi+θ)−ψ′(θ)+1θ−2θ+μi+yi+θ(θ+μi)2], H(\theta) = \sum_i a_i\Big[\psi'(y_i + \theta) - \psi'(\theta) + \tfrac{1}{\theta} - \tfrac{2}{\theta + \mu_i} + \tfrac{y_i + \theta}{(\theta + \mu_i)^2}\Big], where ψ\psi and ψ′\psi' are the digamma and trigamma functions. To keep θ\theta positive the update is made on ϕ=log⁡θ\phi = \log\theta using Uϕ=θUU_\phi = \theta U and Hϕ=θ2H+θUH_\phi = \theta^2 H + \theta U: ϕ←ϕ−Uϕ/Hϕ. \phi \leftarrow \phi - U_\phi / H_\phi . Steps are bounded and halved if the log-likelihood does not increase, and θ\theta is capped at a large value (default 10610^6), at which a warning reports the Poisson limit.

Outer loop. The fit starts from a Poisson IRLS fit and a moment estimate of θ\theta based on Var(Y)=μ+μ2/θ\mathrm{Var}(Y) = \mu + \mu^2/\theta. The IRLS and Newton–Raphson updates are then alternated until the relative change in the log-likelihood falls below 10−1310^{-13}.

2.2 Zero-inflated negative binomial regression

In the ZINB model an observation is a structural zero with probability πi\pi_i and otherwise follows NB(μi,θ\mu_i, \theta), where log⁡μi=xi⊤β+oi\log\mu_i = x_i^\top\beta + o_i and logitπi=zi⊤γ\mathrm{logit}\,\pi_i = z_i^\top\gamma. The covariates ziz_i may differ from xix_i. Writing fNB(0;μ,θ)={θ/(θ+μ)}θf_{NB}(0;\mu,\theta) = \{\theta/(\theta + \mu)\}^\theta, P(Yi=0)=πi+(1−πi)fNB(0;μi,θ),P(Yi=y)=(1−πi)fNB(y;μi,θ),y≥1, P(Y_i = 0) = \pi_i + (1 - \pi_i)f_{NB}(0;\mu_i,\theta), \qquad P(Y_i = y) = (1 - \pi_i)f_{NB}(y;\mu_i,\theta),\ y \ge 1, and E(Yi)=(1−πi)μiE(Y_i) = (1 - \pi_i)\mu_i. The observed-data log-likelihood contains the logarithm of a sum for the zeros, so it is not the log-likelihood of an exponential-family GLM and IRLS cannot be applied to it directly. Had the latent indicators DiD_i (1 for a structural zero) been observed, the problem would separate into a logistic regression for γ\gamma and an NB fit for (β,θ)(\beta, \theta) on the non-structural observations. The EM algorithm exploits this.

E-step. Given current (β,γ,θ)(\beta, \gamma, \theta), compute the posterior probability of a structural zero, τi=P(Di=1∣yi)={πiπi+(1−πi)fNB(0;μi,θ),yi=0,0,yi>0. \tau_i = P(D_i = 1 \mid y_i) = \begin{cases} \dfrac{\pi_i}{\pi_i + (1 - \pi_i)f_{NB}(0;\mu_i,\theta)}, & y_i = 0,\\[2ex] 0, & y_i > 0. \end{cases} In the code this is evaluated as τi=plogis{zi⊤γ−log⁡fNB(0;μi,θ)}\tau_i = \mathrm{plogis}\{z_i^\top\gamma - \log f_{NB}(0;\mu_i,\theta)\} for zeros, which is numerically stable.

M-step, zero part. Maximize ∑i{τilog⁡πi+(1−τi)log⁡(1−πi)}\sum_i \{\tau_i\log\pi_i + (1 - \tau_i)\log(1 - \pi_i)\} over γ\gamma. This is a logistic regression with fractional response τi\tau_i, fitted by IRLS with wi=πi(1−πi),ui=zi⊤γ+τi−πiπi(1−πi). w_i = \pi_i(1 - \pi_i), \qquad u_i = z_i^\top\gamma + \frac{\tau_i - \pi_i}{\pi_i(1 - \pi_i)} .

M-step, count part. Maximize ∑i(1−τi)log⁡fNB(yi;μi,θ)\sum_i (1 - \tau_i)\log f_{NB}(y_i;\mu_i,\theta) over (β,θ)(\beta, \theta). This is exactly the NB fit above with prior weights ai=1−τia_i = 1 - \tau_i, so the same code is reused, warm-started at the current values.

Starting values and convergence. (β,θ)(\beta, \theta) start at the plain NB fit and γ\gamma at a logistic IRLS fit of I(yi=0)I(y_i = 0) on ziz_i. The algorithm stops when the observed-data log-likelihood changes by a relative amount below 10−1210^{-12}. EM never decreases the observed-data log-likelihood, and the package stores the log-likelihood at every iteration so this can be checked directly (Section 4).

2.3 Standard errors

For NB regression, Var̂(β̂)=(X⊤ŴX)−1\widehat{\mathrm{Var}}(\hat\beta) = (X^\top\hat W X)^{-1}, treating θ\theta as known as glm.nb() does, and SE(θ̂)={−H(θ̂)}−1/2\mathrm{SE}(\hat\theta) = \{-H(\hat\theta)\}^{-1/2}.

EM does not produce standard errors, so for ZINB the observed information matrix of the observed-data log-likelihood is computed at the maximum likelihood estimate with respect to (β,γ,log⁡θ)(\beta, \gamma, \log\theta), and its inverse gives the covariance matrix. The Hessian is derived analytically. For each observation let ηi=xi⊤β+oi\eta_i = x_i^\top\beta + o_i, ζi=zi⊤γ\zeta_i = z_i^\top\gamma, and ϕ=log⁡θ\phi = \log\theta. For yi>0y_i > 0 the contribution is log⁡(1−πi)+log⁡fNB\log(1 - \pi_i) + \log f_{NB}, whose second derivatives are those of the NB log-density in (η,ϕ)(\eta, \phi) together with −πi(1−πi)-\pi_i(1 - \pi_i) for ζ\zeta. For yi=0y_i = 0 the contribution is log⁡Pi\log P_i with Pi=πi+(1−πi)f0P_i = \pi_i + (1 - \pi_i)f_0, so each second derivative is Pab/P−PaPb/P2P_{ab}/P - P_aP_b/P^2 with the partial derivatives of PiP_i available in closed form. The per-observation derivatives are assembled into the block Hessian H=(X⊤DηηXX⊤DηζZX⊤dηϕ⋅Z⊤DζζZZ⊤dζϕ⋅⋅∑ihϕϕ,i). H = \begin{pmatrix} X^\top D_{\eta\eta}X & X^\top D_{\eta\zeta}Z & X^\top d_{\eta\phi}\\ \cdot & Z^\top D_{\zeta\zeta}Z & Z^\top d_{\zeta\phi}\\ \cdot & \cdot & \sum_i h_{\phi\phi,i}\end{pmatrix}. The standard error of θ̂\hat\theta follows from the delta method, SE(θ̂)=θ̂SE(log⁡θ̂)\mathrm{SE}(\hat\theta) = \hat\theta\,\mathrm{SE}(\log\hat\theta). As a check, the analytic Hessian is compared with numDeriv::hessian() applied to the package’s own log-likelihood function in Section 4.

3 The R package

The package is available at https://github.com/JosephTruitt/zinbTruitt and installs with

# install.packages("devtools")
devtools::install_github("JosephTruitt/zinbTruitt")

Its main functions are summarized in Table 1.

Both fitting functions return S3 objects (classes "nbreg" and "zinbreg") that store the coefficients, covariance matrix, θ̂\hat\theta and its standard error, log-likelihood, iteration count, convergence flag, fitted values, and the matched call. The methods print, summary, coef, vcov, logLik (with a df attribute, so AIC() and BIC() work), fitted, residuals (Pearson and response), nobs, and predict (with newdata) are provided for both classes. For zinbreg, predict accepts type = "response" for (1−π)μ(1 - \pi)\mu, "count" for μ\mu, and "zero" for π\pi. Wald intervals are available through confint(). Without a | in the formula, zinbreg uses the same covariates in both parts, as zeroinfl() does. The package is documented with roxygen2, tested with testthat (including comparisons against glm.nb() and zeroinfl()), and checked on Windows, macOS, and Linux by GitHub Actions. A short usage example:

fit_nb   <- nbreg(art ~ fem + mar + kid5 + phd + ment, data = bioChemists)
fit_zinb <- zinbreg(art ~ fem + mar + kid5 + phd + ment | fem + kid5 + ment,
                    data = bioChemists)

4 Benchmarking

The fits from nbreg() and zinbreg() were compared with MASS::glm.nb() and pscl::zeroinfl(..., dist = "negbin") on pscl::bioChemists (915 biochemistry PhD students; response art) and AER::NMES1988 (4,406 individuals; response visits). The reference functions were run with tight tolerances (epsilon = 1e-10 for glm.nb() and reltol = 1e-12 for zeroinfl()). The NB models use all covariates in the count part; the ZINB models use the same covariates in the count part and, for bioChemists, in the zero part, and for NMES1988 the covariates of Section 6.

Table 2 reports the maximum absolute differences between the two implementations, and the full side-by-side estimates are in Appendix A. All differences are well inside the required tolerances (the “Theta” column is θ\theta for NB and log⁡θ\log\theta for ZINB). The remaining ZINB differences of order 10−510^{-5} reflect the stopping rules of the two optimizers: on bioChemists, when both are run to very tight tolerances, the coefficients agree to about 2×10−62 \times 10^{-6}.

Table 3 compares median computation times over five fits. The NB fit is about twice as fast as glm.nb(); the ZINB fit is slower than zeroinfl() because EM is a first-order method that needs tens to over a hundred iterations, while BFGS exploits curvature information. The package is not designed to be faster.

Two further checks support the implementation. First, the observed-data log-likelihood never decreased across EM iterations in any ZINB fit (monotone for all fits: TRUE), as theory requires. Second, the analytic Hessian agrees with the numerical Hessian from numDeriv to a maximum relative difference of 1.1e-09 on a ZINB fit to bioChemists with different count and zero covariates.

5 Simulation study

To check that zinbreg() recovers known parameters, R=200R = 200 data sets of size n=500n = 500 were simulated from a ZINB model with one covariate in each part: log⁡μi=1+0.5xi\log\mu_i = 1 + 0.5x_i, logitπi=−1+0.8zi\mathrm{logit}\,\pi_i = -1 + 0.8z_i, and θ=2\theta = 2, with xi,zi∼N(0,1)x_i, z_i \sim N(0,1) independent. The seed was fixed (651). For each parameter, Table 4 reports the mean estimate, the bias, the Monte Carlo standard deviation of the estimates, the mean of the estimated standard errors, and the empirical coverage of 95% Wald intervals. The parameter log⁡θ\log\theta is reported because the Wald interval is constructed on that scale.

All 200 of the 200 fits converged. Biases are small relative to their Monte Carlo standard errors (the largest absolute bias is 0.034), and the mean estimated standard errors are close to the Monte Carlo standard deviations, though slightly smaller for some parameters, as is typical of Wald standard errors at moderate sample sizes. Coverage ranges from 0.915 to 0.960. With 200 replicates the Monte Carlo error of a coverage proportion is about 0.015, so the lowest value is within sampling error of the nominal level, although it hints that the intervals for the count intercept are a little liberal.

6 Data analysis: physician office visits in NMES1988

6.1 Data and models

The NMES1988 data contain the number of physician office visits (visits) for 4,406 individuals aged 66 and over in the 1987–88 US National Medical Expenditure Survey (Deb and Trivedi, 1997; Zeileis, Kleiber and Jackman, 2008). The covariates are the number of hospital stays (hospital), self-perceived health (health: poor, average, excellent; average is the reference), the number of chronic conditions (chronic), gender, years of education (school), and private insurance (insurance). A Poisson model (fitted with glm() for reference), an NB model, and a ZINB model were fitted. All three use hospital, health, chronic, gender, school, and insurance in the count part; the ZINB zero part uses hospital, chronic, gender, school, and insurance, the minimum set suggested in the project instructions (health was left out of the zero part to keep it to the suggested set).

6.2 Overdispersion and excess zeros

The mean number of visits is 5.77 while the variance is 45.69, a variance-to-mean ratio of 7.9. After adjusting for the covariates the overdispersion remains: the Pearson chi-square statistic divided by the residual degrees of freedom from the Poisson model is 6.71, far above the value of one expected under a correct Poisson model. Zeros are also more common than the Poisson model predicts: 683 of the 4406 individuals (15.5%) had no visits, whereas the Poisson model expects only 47. Figure 1 compares the observed frequencies of small counts with those expected from the three models.

6.3 Model comparison

Table 5 shows that the NB model improves on the Poisson model by thousands of log-likelihood units, confirming the overdispersion. The ZINB model improves on the NB model by a further 79.8 log-likelihood units for six additional parameters; AIC falls by 147.7 and BIC by 109.3, so both criteria favor ZINB. The NB model underpredicts the number of zeros (608 expected against 683 observed), and the ZINB model slightly overpredicts it (709), but is much closer to the observed value in relative terms (an error of 26 zeros against 75 for NB).

6.4 Estimates and interpretation

Table 6 reports incidence rate ratios (IRRs, eβ̂e^{\hat\beta}) from the NB model and from the count part of the ZINB model, and Table 7 reports odds ratios (ORs, eγ̂e^{\hat\gamma}) for the zero part of the ZINB model, all with 95% Wald confidence intervals.

Count part (NB and ZINB). The two models agree qualitatively. Holding the other covariates fixed, each additional chronic condition is associated with 19% more expected visits in the NB model (IRR 1.19) and 14% more in the count part of the ZINB model (IRR 1.14). Each additional hospital stay is associated with about 22% more visits (ZINB IRR 1.22). People in poor health are expected to make 33% more visits than people in average health (IRR 1.33), and people in excellent health 27% fewer (IRR 0.73). Private insurance is associated with 13% more visits (IRR 1.13), and each year of education with about 2% more. Men are expected to make 8% fewer visits than women in the ZINB count part (IRR 0.92), a smaller difference than in the NB model (IRR 0.88). The IRRs of the ZINB count part are generally closer to one than those of the NB model for chronic conditions, gender, and insurance, because part of what the NB model attributes to those covariates is absorbed by the zero part.

Zero part (ZINB). The zero part describes the odds of belonging to the group that has no visits regardless of circumstances. Each additional chronic condition multiplies the odds of being a structural zero by 0.29, a reduction of 71%. Private insurance multiplies the odds by 0.31 (69% lower), and each year of education by 0.92. Men have 1.91 times the odds of women of being structural zeros (91% higher). The effect of hospital stays is borderline (OR 0.45, p=p = 0.0571). In short, healthier, uninsured, less educated men are the most likely to be non-users of physician office care, and among users, sicker people visit more often. Because these odds ratios come from a latent class, they should be read as statements about a modeled non-user group, not as directly observed behavior.

6.5 Which model do we prefer?

The ZINB model is the better description of these data. It has much lower AIC and BIC than the NB model, it reproduces the number of zeros much better, and its zero-part effects (chronic conditions, insurance, gender, education) are strong and plausible rather than weakly identified. The estimated dispersion parameter also rises from θ̂=\hat\theta = 1.21 to 1.48 (larger θ\theta means less overdispersion), which means that some of the apparent overdispersion in the NB fit was really excess zeros. The cost is complexity: the model has six more parameters and its structural-zero interpretation is a modeling device that the data alone cannot confirm. The slight overprediction of zeros by the ZINB model and the large remaining dispersion (θ̂\hat\theta is still small) suggest that a hurdle model or a model with additional covariates in the zero part could be explored, but within the NB family the ZINB model is clearly preferred here.

7 Discussion

The package reproduces glm.nb() and zeroinfl() to well within the required tolerances using only IRLS, Newton–Raphson, and EM, and the simulation shows that it recovers known parameters. Several limitations are worth noting. EM converges linearly, so ZINB fits take more iterations and more time than the quasi-Newton optimizer used by zeroinfl(), particularly when the zero part is weakly identified. When the data support no zero inflation, the maximum likelihood estimate lies on the boundary π→0\pi \to 0; the zero-part intercept then diverges to −∞-\infty and its standard error is meaningless, as happens for art ~ ment | 1 on bioChemists, where the package and zeroinfl() agree on everything except the arbitrary value reached by that intercept. The likelihood of a mixture can have several local maxima, and the package uses a single starting strategy. Standard errors are Wald-type and treat the model as correctly specified, and the NB standard errors treat θ\theta as known. The package supports offsets only in the count part, has no user-facing prior weights, and uses only the log link for the count model and the logit link for the zero model. Natural extensions are zero-inflated Poisson and hurdle models, likelihood-ratio or Vuong tests for the zero part, profile-likelihood or bootstrap intervals, observation weights, and a compiled implementation of the inner loops.
