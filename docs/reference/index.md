# Package index

## Model fitting

Negative binomial and zero-inflated negative binomial regression.

- [`nbreg()`](https://JosephTruitt.github.io/zinbTruitt/reference/nbreg.md)
  : Negative binomial regression by IRLS and Newton-Raphson
- [`zinbreg()`](https://JosephTruitt.github.io/zinbTruitt/reference/zinbreg.md)
  : Zero-inflated negative binomial regression by EM with IRLS M-steps

## Control settings

- [`nbreg_control()`](https://JosephTruitt.github.io/zinbTruitt/reference/nbreg_control.md)
  : Control parameters for negative binomial regression
- [`zinbreg_control()`](https://JosephTruitt.github.io/zinbTruitt/reference/zinbreg_control.md)
  : Control parameters for zero-inflated negative binomial regression
