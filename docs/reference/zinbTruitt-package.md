# zinbTruitt: NB and ZINB regression via IRLS and EM

Fits negative binomial regression
([`nbreg()`](https://JosephTruitt.github.io/zinbTruitt/reference/nbreg.md))
and zero-inflated negative binomial regression
([`zinbreg()`](https://JosephTruitt.github.io/zinbTruitt/reference/zinbreg.md))
without general-purpose optimizers.
